## 💡 ¿Qué es KODI AI Studio?

**KODI AI Studio** es un entorno de trabajo con inteligencia artificial diseñado para desarrolladores, estudiantes, investigadores e ingenieros de software. Combina orquestación multi-modelo inteligente, ejecución de código en tiempo real, búsqueda web con grounding mediante Tavily AI y pagos descentralizados en USDT (red BEP20).

### Características Principales

- **Multi-Modelo Inteligente**: Alterna con fluidez entre **KODI Nova Core 2.1**, **KODI Omniscient 3.0** y **KODI Max Engineering 4.5**.
- **Ejecución y Auditoría de Código**: Entorno de ejecución para Python, JavaScript y Bash con métricas de tiempo y rendimiento.
- **Búsqueda Web en Vivo**: Consultas en tiempo real verificadas mediante Tavily AI con citas y referencias directas.
- **Monetización Cripto Transparente**: Activación directa de planes Pro y Max con USDT (BEP20) y verificación en Binance Smart Chain.
- **Privacidad y Control de Datos**: Sin venta de información para entrenamiento, estricto apego a GDPR/CCPA y derecho a borrado total en 48 horas.

## 🌟 Stack Tecnológico

**Frontend:**
- React 19 + TypeScript
- Vite (builder)
- UI moderna y responsiva

**Backend:**
- Express + Node.js
- Google Cloud Run deployment
- Rate limiting por plan

**IA & ML:**
- Google Gemini (Nova Core 2.1, Max Engineering 4.5)
- Groq Llama 3.3 70B (Omniscient 3.0)
- Tavily AI Search

**Blockchain & Pagos:**
- USDT BEP20 (Binance Smart Chain)
- Etherscan API verification
- Suscripciones criptográficas

**Seguridad:**
- JWT Authentication
- GDPR/CCPA Compliant
- Encriptación end-to-end
- Logging de auditoría
