## 💡 ¿Qué es KODI AI Studio?

**KODI AI Studio** es una plataforma de inteligencia artificial autónoma multiplataforma (Web y Android APK nativo) diseñada especialmente para ingenieros de software, analistas, investigadores y estudiantes autodidactas. Integra modelos de última generación con orquestación en cascada, ejecución aislada de código, auditoría de librerías y búsqueda web en tiempo real mediante Tavily AI.

### ⚡ Características Principales

- **Multi-Modelo Autónomo**: Alterna dinámicamente entre **KODI Nova Core 2.1**, **KODI Omniscient 3.0** y **KODI Max Engineering 4.5**.
- **Ejecución y Auditoría de Código**: Intérprete para Python, JavaScript y comandos shell en entornos controlados.
- **Búsqueda Web en Vivo**: Grounding directo mediante Tavily AI para evitar alucinaciones.
- **Monetización Cripto**: Suscripciones Pro y Max validadas on-chain mediante USDT (BEP20 Binance Smart Chain).
- **Privacidad Real**: Sin venta de datos, GDPR/CCPA compliant, eliminación en 48 horas.

## 🌟 Stack Tecnológico

**Frontend:**
- React 19 + TypeScript
- Vite (builder)
- UI moderna y responsiva

**Backend:**
- Express + Node.js
- Google Cloud Run deployment
- Rate limiting por plan

**AI & ML:**
- Google Gemini (Nova Core 2.1, Max Engineering 4.5)
- Groq Llama 3.3 70B (Omniscient 3.0)
- Tavily AI Search

**Blockchain & Pagos:**
- USDT BEP20 (Binance Smart Chain)
- Etherscan API verification
- Suscripciones criptográficas

**Seguridad:**
- JWT Authentication
- GDPR/CCPA Compliant
- Encriptación end-to-end
- Logging de auditoría
