## 💡 ¿Qué es KODI AI Studio?

**KODI AI Studio** es una plataforma de inteligencia artificial autónoma multiplataforma (Web y Android APK nativo) diseñada especialmente para ingenieros de software, analistas, investigadores y estudiantes autodidactas. Integra modelos de última generación con orquestación en cascada, ejecución aislada de código, auditoría de librerías y búsqueda web en tiempo real mediante Tavily AI.

### Características Principales

- **Multi-Modelo Autónomo**: Alterna dinámicamente entre **KODI Nova Core 2.1**, **KODI Omniscient 3.0** y **KODI Max Engineering 4.5**.
- **Ejecución y Auditoría de Código**: Intérprete para Python, JavaScript y comandos shell en entornos controlados con verificación de rendimiento.
- **Búsqueda Web en Vivo**: Grounding directo mediante Tavily AI para evitar alucinaciones con fuentes verificables.
- **Monetización Cripto Descentralizada**: Suscripciones Pro y Max validadas on-chain mediante USDT (BEP20 Binance Smart Chain).
- **Enfoque de Privacidad Real**: Sin venta de datos, compatible con GDPR/CCPA y eliminación irreversible en 48 horas bajo solicitud.
