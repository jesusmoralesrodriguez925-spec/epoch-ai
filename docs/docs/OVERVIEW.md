# OVERVIEW: ¿Qué es KODI AI Studio?

> **Epoch** — *"Inteligencia Artificial Accesible para Todos"*

---

## 🌟 1. Introducción

En el panorama actual de la inteligencia artificial, las herramientas disponibles suelen dividirse en dos extremos: interfaces monolíticas costosas cerradas a suscripciones rígidas, o APIs fragmentadas difíciles de configurar para estudiantes y desarrolladores independientes.

**Epoch** nace como una startup digital fundada bajo una premisa fundamental: crear un entorno de ingeniería autónomo, potente y transparente, capaz de funcionar con fluidez tanto en dispositivos móviles de gama media como en navegadores web de escritorio de alto rendimiento.

**KODI AI Studio** es el primer producto insignia de Epoch. No es simplemente una ventana de chat: es un agente orquestador que analiza el contexto de tu consulta, selecciona la mejor arquitectura de modelo y ejecuta tareas de codificación, verificación web y razonamiento matemático en milisegundos.

---

## 🎯 2. Misión y Visión

### Misión
Democratizar el acceso a la inteligencia artificial avanzada para programadores, estudiantes y creadores de tecnología en todo el mundo, eliminando barreras geográficas y bancarias tradicionales mediante micropagos cripto descentralizados y arquitectura de código abierto eficiente.

### Visión
Convertir a **KODI** en el copiloto y socio autónomo de referencia para el desarrollo de software global, capaz de diseñar, compilar, auditar y desplegar sistemas completos de extremo a extremo desde cualquier terminal o dispositivo móvil.

## 🚀 4. ¿Por qué elegir KODI?

1. **Optimización Extrema de Recursos**: Diseñado con React 19 y Node.js Express de latencia mínima.
2. **Pensamiento Crítico y Razonamiento Transparente**: Despliegue de cadenas de razonamiento (Chain of Thought) auditables antes de entregar una respuesta técnica.
3. **Creado por y para Desarrolladores**: Con soporte nativo para edición de código con sangría de tabulación, resaltado de sintaxis, exportación de archivos y temas ergonómicos para la vista.
